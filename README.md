# 🛒 Interactive Cashier System

A terminal-based Cashier System and Invoice Calculator designed to handle product input, compute total costs, and output clean receipts.

## ✨ Features
- **Dynamic Cart**: Add multiple items with custom quantities and unit prices.
- **Robust Validation**: Ensures valid numeric inputs for price and quantity.
- **Automated Receipt**: Generates a formatted summary showing total bill calculations.
- **Error Prevention**: Handles invalid numeric entries gracefully without breaking execution.

## 🛠️ Concepts & Technologies
- Python 3.x
- Data Structures: Dictionaries & Lists
- Functional Logic & Loops
- Exception Handling (`ValueError`)
